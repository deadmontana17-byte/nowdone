# Глобальные правила

- **Язык**: Все комментарии и логирование — на английском. Интерфейс и сообщения пользователю — на русском.
- **Безопасность**: Никогда не хардкодить секреты. Все переменные окружения читаются через `os.Getenv` (Go) или `import.meta.env` (React).
- **Обработка ошибок**: Все ошибки должны логироваться в консоль и возвращаться клиенту с понятным сообщением. На фронте — показывать через MUI Snackbar.
- **Код-стайл**: Go — стандартный `gofmt`; TypeScript — использовать `interface` для пропсов, `type` для сложных типов.
- **Коммиты**: Соблюдать Conventional Commits (feat:, fix:, docs:, etc.).
